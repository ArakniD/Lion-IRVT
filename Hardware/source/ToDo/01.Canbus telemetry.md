## Update the CANBUS telemetry for slot 1-8 - Pack voltage, current, mAh and mWh into single packet

Byte 0: Slot index and run state bitset
--Bits 0-3 Slot number 0-7
--Bits 4-7 Charging:Discharging:Paused:Fault
--- Charging is in charge mode
--- Discharging is in discharge mode
--- Paused if the slot is in paused mode, charge and discharge flags can be set
--- Fault for any hardware trips or faults on the slot preventing action
Byte 1-2: Voltage
--- 16bit value in mV (signed)
Byte 3-4: Current
--- 16it value in mA (signed)
Byte 5-7: mAh and mWh as 12 bit values
--- Byte 5 + byte 6[0:3] = mAh / 4 aka maximum 16,384 mAh
--- Byte 6[4:7] + byte 7 = mWh / 16 aka maximum 65,535 mWh
